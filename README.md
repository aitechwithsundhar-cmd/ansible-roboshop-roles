# Roboshop — Ansible Roles 🎭

Roboshop deployment refactored into modular, reusable Ansible
roles — Phase 3 of the Roboshop project evolution.

## Improvement over Playbooks
- Modular role-based structure
- Reusable across multiple projects
- Jinja2 templating for dynamic configs
- Follows Ansible best practices

## Role Structure
- mongodb/ redis/ mysql/
- rabbitmq/ nginx/ catalogue/
- user/ cart/ payment/ shipping/
